Welcome to Xiros Border Block

This mod is intended to be a simple add-on for border related functions.

It is not intended for all purposes but maybe in the future I'll add more.

General disclosure: This mod is in early development and may contain bugs or incomplete features. Use at your own risk.

Some functionalities: 

- Border Block: a block that accepts items, increases the border size, and rewards the player with a border bundle.
- Border Bundle: a configurable item that rewards the player when the border is increased through the border block.
- Hoarder Mode: a game mode that increases the border size when a new item is found by a player.
- Hoarder Screen: to see missing/found blocks
